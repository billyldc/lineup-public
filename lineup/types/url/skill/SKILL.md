# URL Links

Objects of type `url` are web links (http:// or https://).

## How to identify

- Targets start with `http://` or `https://`

## How to open

Use `lineup_open_object` — opens the URL in the default browser.

## Tips

- URLs cannot be "read" directly from lineup — use WebFetch if you need the page content
- Common use cases: arxiv papers, GitHub repos, documentation pages, project boards
